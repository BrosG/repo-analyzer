# GitHub Repository Analyzer

AI-powered GitHub repository analysis tool that provides intelligent issue recommendations, code insights, and project health summaries.

## Features

- Generate intelligent issue recommendations
- Analyze code quality and structure
- Gain insights from any GitHub repository
- Multi-AI provider support (OpenAI, Claude, Deepseek)

## Getting Started

### Prerequisites

- A web browser with extension support (Chrome recommended)
- The [APIKeyConnect](https://chromewebstore.google.com/detail/apikey-connect/edkgcdpbaggofodchjfkfiblhohmkbac) extension installed
- API keys for one or more supported AI providers

### Installation

1. Clone this repository
2. Open index.html in your browser or host it on a web server
3. Connect your AI provider API key using the APIKeyConnect extension
4. Enter a GitHub repository URL and start analyzing!

## Usage

1. Enter a GitHub repository URL
2. Select your preferred AI provider
3. Choose the depth of analysis
4. Click "Analyze Repository"
5. Review the generated insights and recommendations
